# Policy resolution and practical significance

Let a validated complete divergent set D be a disjoint union of intervals with explicitly owned endpoints. Let P_d={k/10^d : L<=k/10^d<=H} be the application's declared finite decimal policy set. For a component with endpoints l,r, the first permitted integer is ceil(l*10^d) when its left endpoint is included, otherwise floor(l*10^d)+1. The last is floor(r*10^d) when its right endpoint is included, otherwise ceil(r*10^d)-1. The exact intersection count is max(0,last-first+1). Disjoint-component counts can be summed. This is finite-domain restriction using exact integer bounds, not sampling or a new general parameter-synthesis theorem.

A closed singleton can intersect P_d even with PSC=0; the added test checks this explicitly. Equality on P_d does not establish equality over the continuous domain, and a numeric tolerance never silently erases an exact interval certificate.

The recorded maximal changed-ID count is obtained from all independently checked point/open-atom representatives, whose memberships are constant within each atom. It concerns a single policy choice. Precision shortfall is different: alpha minus the selected set's exact precision varies linearly within an atom. The largest stored-probe shortfall is an observed quantity. The separately reported supremum also checks the right-end limit of every open atom and may be unattained. No operational probability, data frequency, loss, or universal CI budget is inferred from either quantity.

The additional binary64 policy examples embed a float by its exact integer ratio. Decimal targets embed their specified decimal rational value; these are not interchangeable. For the measured thirty eval-toolkit workloads, the complete divergent regions contain no target in the four tested decimal lattices. This limits the operational significance of those near-boundary differentials for an application whose contract permits only such targets. Strict numerical-contract audit, migration documentation and permitted-set intersection remain narrower possible uses; no deployment effectiveness study has been performed.

The separate SciPy #6318 study concerns a documented integer-overflow defect with broad policy propagation. Its fixed/current nearest interpolation must reproduce observed knot values. Its thirty pipeline time-axis carriers are designed propagation fixtures, not naturally collected time-series deployments. Neither these workloads nor the numerical-contract workloads are pooled into a real-bug detection rate.

Applying the same declared-set intersection separately to the SciPy core certificates yields 31/36 affected workloads and 1,611 of 2,196 permitted two-decimal policy/workload pairs. The detailed counts are retained at all four resolutions. If an application already has a small fixed finite policy set, exhaustive enumeration of that set is already complete; the continuous certificate offers reusable region diagnostics rather than a uniquely necessary verification procedure.
