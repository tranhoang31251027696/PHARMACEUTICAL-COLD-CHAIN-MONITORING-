## External defect provenance

The scikit-learn issue #23213 describes truncation at full recall. Its upstream maintainer discussion accepts the issue, and merged PR #23214 links the fix and a non-regression test. Both pages were inspected directly. Public GitHub API metadata provided the merge commit. Full source files and BSD COPYING files were fetched from immutable commits and bound by SHA-256. A candidate release tag, 1.1.0, was inspected and found still to contain the truncation path; the study therefore uses the actual merge commit rather than assuming that release includes the fix.

The source nodes are executed unchanged with an explicitly documented modern counting bridge. The case is not described as historical binary reproduction, a new bug discovery, a multi-project defect corpus, or a clinical/model-quality result. There were no upstream messages or submissions. Issue-origin protocol inputs and thirty inherited pipeline workloads are separated in the data manifest.

## Inclusion and exclusion decisions

Included: an upstream issue closed by a merged fix with source available; an external general solver applied on an explicitly matched contract; primary foundations that constrain novelty claims. Excluded as confirmed defects: the SciPy numerical differentials, an untriaged ROC issue, and requests to add plotting options. Excluded as empirical direct competitors: probabilistic-model tools without a faithful common-property encoding. The study does not infer absence of a capability from its absence in inspected examples.

Coverage still lacks exhaustive database search, full citation closure, multiple independent selector projects and historical binary validation of the scikit-learn defect. Twenty reference entries include project documentation and issue/PR records; this is not a claim of twenty peer-reviewed comparative studies or proven Q1-level novelty.
