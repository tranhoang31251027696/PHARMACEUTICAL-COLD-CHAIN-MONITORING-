# Contract and reasoning for allowed policy queries

The input is a successfully verified core finite-input certificate, its original labels, old/new scores and unique aligned observation IDs. `verified_answer` runs the independent streaming checker before exposing a result. The lower-level `answer` function explicitly requires an already verified object; callers must not use it as a verifier. Verification checks full critical-point coverage, cell ownership, actual selected memberships, witnesses and metrics under the two declared selectors. Source admission, frozen labels and application choice of numeric semantics remain trust boundaries described in the main paper.

The allowed query is either a nonempty finite rational set, a nonempty rational interval with explicit Boolean endpoint ownership, or the intersection of that interval with integer multiples of 10^(-d), 0 <= d <= 12. Every query must lie within the certificate's verified domain. Numeric JSON floats are refused instead of silently treating them as decimal rationals. Binary64 embeddings require a different explicitly modeled contract; this interface does not answer them. Unsupported or empty domains raise errors, not an equivalence verdict.

For each unequal certificate cell, intersect with the permitted interval. At a shared lower endpoint inclusion requires all active lower-bound constraints to include equality; the upper endpoint is analogous. An intersection of equal endpoints survives exactly when both sides are closed. Because the verified cells are disjoint with correct ownership, their nonempty intersections are disjoint. Their union is precisely the permitted divergent set. A member of any such intersection is a witness. No intersections establishes equality only on this allowed interval and these frozen inputs.

For a lattice with scale s = 10^d, an interval [l,h] contributes integers from ceil(s*l) through floor(s*h), removing an endpoint integer if its corresponding boundary is open. Its count is max(0,last-first+1). Counts sum without duplicate endpoints because the underlying cells are disjoint. This also counts a closed singleton correctly even though its interval length is zero. Finite sets are deduplicated and tested for cell membership directly. These arguments are elementary set intersection and integer arithmetic, not new parameter-synthesis theory or a machine-checked proof.

After verification, an interval/lattice query scans C cells, requiring O(C) rational operations and O(C) output storage for explicitly retained intersections. A finite set of M distinct policies uses O(M*C) membership checks in this implementation. Arbitrary-precision operand size matters. Initial verification, certificate construction/storage and future input changes are separate costs; no measured break-even or end-to-end query speed superiority is inferred. A small fixed finite set can be exhaustively checked directly. The study's direct enumeration uses cached actual interpolation scores and independent candidate masks, not a fresh interpolation call per target.

`tests/test_domain_query.py` exercises singleton lattice counts, excluded boundaries, finite-set deduplication and refusal of semantic/domain mismatches. `validate_v7.py` also verifies that modified source input vectors are rejected before query reuse. `domain_query_study.py` checks all 288 declared scenarios against direct selected-bitset SMT encoding and 24,408 policies by explicit enumeration where specified. These are finite implementation checks and functional reuse evidence, not independent developer triage or deployment evaluation.
